# מערכת אישורי הגעה

מערכת לניהול מוזמנים, שליחת הזמנות בוואטסאפ ומעקב אחרי אישורי הגעה.

## טכנולוגיות

- **Next.js** (אתר + שרת) עם Tailwind, בעברית ומימין לשמאל
- **Supabase** (מסד נתונים PostgreSQL + התחברות)
- **Vercel** (אחסון)

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # ולמלא את המפתחות
npm run dev                  # http://localhost:3000
```

## הקמת מסד הנתונים

1. פותחים פרויקט ב-[supabase.com](https://supabase.com) (אזור: Frankfurt, הכי קרוב לישראל).
2. SQL Editor > New query > מדביקים את `supabase/migrations/0001_initial_schema.sql` > Run.
3. Project Settings > API > מעתיקים את ה-URL ואת שני המפתחות ל-`.env.local`.

## מבנה

```
src/app/                  דפים
supabase/migrations/      סכמת מסד הנתונים
```
